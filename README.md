# Casablanca Restaurant 3D

## تشغيل المشروع

```bash
npm install
npm run dev
```

افتح الرابط الذي يظهر في Terminal.

## دخول الإدارة المخفي
اضغط على شعار CASABLANCA خمس مرات، ثم أدخل كلمة السر:

```txt
123456
```

## تغيير الصور
ضع الصور داخل:

```txt
public/images/
```

ثم من صفحة الإدارة غيّر مسار الصورة مثل:

```txt
/images/kebab.jpg
```

أو استبدل الصورة بنفس الاسم.

## ملاحظة
الداتا محفوظة حاليًا في localStorage حتى يشتغل المشروع فورًا بدون XAMPP. ملف `src/firebase.js` جاهز لوضع إعدادات Firebase لاحقًا.
